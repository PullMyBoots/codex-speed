# 首次发布的验证范围

后续新增的 **0.160.0–0.163.0** 源码移植、编译检查和原生运行结果见 [兼容性验证记录](COMPATIBILITY.md)。本页保留首次发布时的验收范围；当前 Python 测试新增了实际 Git 补丁选择、重复应用、未知版本尝试与冲突保护，17 项单元测试通过，原生终端测试另行按目标包执行。

验证日期：2026-10-16。实际环境为 Linux x86_64，原生补丁基于上游 `rust-v0.163.0`（提交前缀 `83086188ae06`）。

## 安装器与渲染器

```bash
python3 -m unittest discover -s tests -v
```

13 项单元测试通过；未设置原生测试包时，额外的终端集成测试跳过。覆盖安装与重复安装、普通文件和符号链接的备份恢复、卸载入口独立运行、含空格/单引号路径、用户修改后的入口保护、缺少备份时停止卸载、原配置保留、原生程序启动失败时保留原入口、缺少运行资源时在下载前报错，以及测速阶段与无效采样的渲染。

## 实际原生终端集成

```bash
python3 -m pip install -r tests/requirements.txt
CODEX_SPEED_TEST_PACKAGE=/path/to/patched/package \
  python3 -m unittest discover -s tests -p test_terminal.py -v
```

使用已构建的完整原生包，通过本仓库安装器安装到隔离目录，再启动实际 `codex-speed` 入口。测试以伪终端、本地模拟 Responses SSE 服务和 Python 渲染器运行，结束后执行卸载。没有调用真实模型或付费 API。

实际通过的检查：

- 正文、普通工具参数、原始思考和摘要四类流都有有效实时样本；摘要单独显示 `Summary`。
- 约 40 tokens/s 的模拟正文流测得 **39.51 tokens/s**，正文采样时长 **987 ms**；这是模拟流验证结果，不是某个真实模型的性能。
- 收集到 37 个有效实时样本，原生事件声明的采样间隔为 100 ms。
- 首 token 等待、工具执行与段间等待未计入 decode 时长；摘要不混入 decode 累计。
- 后续只有缓冲输出、无法独立测速的请求仍保留最近有效值。
- 120 列与 83 列终端中，测速行和原生状态栏都可见且分行。
- 累计用量为模拟服务报告的 1,161 output tokens；累计用量没有用作实时吞吐率分母。
- 安装路径含空格、单引号仍可启动和卸载。

## 原生构建与补丁

本次复用的原生包此前已从上述源码完整编译，CLI 与 code-mode-host 均可运行；原生吞吐跟踪器的 8 项定向测试已通过。分发补丁通过了相对于干净上游 HEAD 的 `git apply --cached --check`；对已有补丁的源码，安装器也能识别为 `already applied`。

安装器的构建命令沿用该成功构建路径，V8 下载与两层 SHA256 校验遵循源码中的上游 `setup-rusty-v8` 操作。**本次发布没有在全新系统上清空依赖后重新执行一遍自动下载与完整编译**，因此不能把上述复用安装测试当作干净机器安装验收。

## 尚未验证与测量边界

- macOS、WSL2、其他 CPU 架构和其他 Codex 源码标签未做完整实机验收。没有版本白名单，补丁冲突仍需要代码适配。
- GitHub Actions 只运行 Python 单元测试，不下载完整 Codex 或编译 Rust。
- 数值使用客户端收到的流与估算分词。网络缓冲、模型 tokenizer 差异和隐藏推理会影响结果；不能据此声称精确测得服务端 GPU 吞吐率。
- 官方隐藏推理无法实时计数；摘要仅代表摘要流。单个缓冲 chunk 或短于采样条件的流可能没有新速度。
